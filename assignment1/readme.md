- Dog Playzone Website
- Welcome to the Dog Playzone Website! A fun and interactive platform for dog lovers to explore services and contact the playzone.
- Project Structure:
1. `index.html`: Main webpage structure.
2. `styles.css`: Styling for the website.
3. `img.icons8.com.png`: Favicon.
4. `mixkit-happy-puppy-barks-741.wav`: Playful dog bark audio.
5. `9898282-uhd_3840_2160_24fps copy.mp4`: Playzone activity video.
- Features:
1. `Playful Design`: Vibrant colors and fun fonts.
2. `Media Integration`: Embedded images, audio, and video.
3. `Contact Form`: Interactive form with input validation.
4. `Service Table`: Colorful pricing table.
- Technologies Used:
1. `HTML5`: Webpage structure.
2. `CSS3`: Styling.
- How to Run:
1. Clone or download the files.
2. Open index.html in a browser.
3. Ensure all media files are in the same directory.
