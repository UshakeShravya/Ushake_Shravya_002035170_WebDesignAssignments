# Portfolio Website
This is my personal portfolio website, built with HTML and CSS. It highlights my education, skills, projects, and provides a way for potential employers or collaborators to contact me.

### Features:
Header Section: Contains my name, location, and a navigation bar to easily access different sections of the page.
About Section: A brief introduction about myself and my aspirations in the tech field.
Education Section: A table showcasing my academic history with details about my degree and institutions.
Skills Section: A list of technical skills that I am proficient in.
Projects Section: A display of my featured project, the "Multipurpose Delivery Robot," with an overview and images.
Testimonials Section: Quotes from professors and mentors about my academic performance and professional demeanor.
Contact Section: An interactive form that allows visitors to contact me.
### Tags Used in HTML:
1. `<!DOCTYPE html>`
Defines the document type and version of HTML (HTML5).
2. `<html lang="en">`
Specifies the language of the document (English in this case).
3. `<head>`
Contains meta-information about the webpage such as character encoding, viewport settings, title, and external links to stylesheets or icons.
4. `<meta charset="UTF-8">`
Defines the character encoding for the document (UTF-8 allows for a wide range of characters).
5. `<meta name="viewport" content="width=device-width, initial-scale=1.0">`
Ensures that the webpage is responsive and adjusts to different screen sizes by setting the viewport width.
6. `<title>`
Sets the title of the webpage that appears in the browser's tab.
7. `<link rel="stylesheet" href="styles.css">`
Links to the external CSS file that styles the webpage.
8. `<link rel="icon" href="portfolio.png">`
Specifies the icon displayed in the browser tab.
9. `<body>`
Contains the visible content of the webpage.
10. `<header>`
Defines the introductory content at the top of the page, including the navigation and introductory details.
11. `<nav>`
Contains the navigation menu, allowing users to navigate between different sections of the webpage.
12. `<ul> and <li>`
Used to create an unordered list for the navigation links.
13. `<section>`
Defines distinct sections of the webpage (e.g., About, Education, Projects, etc.).
14. `<h1>, <h2>, <h3>`
Header tags used for titles and subtitles, with `<h1>` being the highest-level heading and `<h2> <h3>` used for subheadings.
15. `<p>`
Defines a paragraph of text.
16. `<center>`
Centers the content within the element (e.g., text or tables).
17. `<table>, <tr>, <th>, <td>`
Used to create a table structure. `<th> `represents header cells, `<td> `represents data cells, and `<tr>` is used to define each row in the table.
18. `<ul> `and `<li>` (Skills Section)
Used to create an unordered list of skills.
19. `<div class="container">`
Used as a container for each section to align and style the content.
20. `<img>`
Used to embed images in the webpage.
21. `<form>`
Defines the form elements, allowing users to input data for the contact form.
22. `<input>`
Creates input fields for the contact form (name, email, phone, etc.).
23. `<textarea>`
Creates a multi-line text field for a message in the contact form.
24. `<button>`
Creates a clickable button for submitting the form.
25. `<footer>`
Defines the footer section, where I include my contact email.
